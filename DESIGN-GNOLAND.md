# GNOLAND — Direção visual e editorial

Este arquivo define a identidade base do site GNOLAND, que reúne as mesas de Ordem Paranormal de um universo compartilhado. É uma web interativa, com espaço futuro para quizzes, minijogos, experiências e páginas conectadas.

## Direção estética aprovada

A inspiração estética vem de quatro referências visuais fornecidas pelo criador do projeto. Usar apenas a linguagem visual dessas referências, não reproduzir suas imagens, criaturas, textos ou fichas.

- Gênero: terror e investigação, mistério inquietante e atmosfera de desconhecido.
- Ilustração: gravura obscura, impressão de xilogravura/risografia, hachuras manuais, retículas, textura de papel envelhecido, marcas de impressão desalinhada, contrastes fortes e formas inquietantes.
- Paleta: preto quase absoluto, vermelho de sangue, azul-esverdeado frio e amarelo envelhecido; evitar visuais genéricos de dashboard futurista.
- Tipografia: blackletter/gótica e serifas ornamentais para títulos, serifas antigas para textos corridos, máquina de escrever para notas e registros; priorizar legibilidade.
- Composição: página editorial e grimório/arquivo ilustrado, tratamento analógico, layout assimétrico cuidadosamente controlado, elementos visuais que parecem impressos e desgastados.
- Interação: efeitos sutis ao passar o mouse, seleção de arquivos e microinterações; respeitar prefers-reduced-motion, teclado e dispositivos móveis.

## Regras de conteúdo

- Nome principal: GNOLAND.
- Casos definidos: A Maldição de Heredistho; O Culto do Príncipe; O Cataclisma.
- As campanhas fazem parte do mesmo universo, mas cada uma terá sua própria área.
- Não inserir histórias, eventos, personagens, monstros, símbolos próprios, teorias ou spoilers provenientes de outras conversas. Apenas o criador determina o que entra no site.
- Os símbolos temporários existentes são genéricos e decorativos; não são marcas oficiais dos casos.
- Não reutilizar as quatro imagens de referência como assets sem um pedido explícito.
- Não criar textos extensos de lore apenas para preencher o layout; usar textos de navegação e placeholders claramente identificados.

## Estrutura técnica vigente

Site estático com index.html, styles.css e script.js, compatível com GitHub Pages, sem backend nesta etapa. A experiência poderá crescer modularmente.
